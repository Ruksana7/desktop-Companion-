Place your two transparent-background GIF assets in this folder:

  idle.gif   - the character sitting/idling, loops forever
  drink.gif  - the character walking in and drinking, plays once then
               the app automatically switches back to idle.gif

Notes:
- Both GIFs should use transparency (not a solid background color) so the
  window shows only the character over the desktop.
- Frame size doesn't need to match AppConfig.windowSize exactly —
  imageScaling is set to scaleProportionallyUpOrDown — but matching the
  GIF's aspect ratio to the 220x220 default window avoids letterboxing.
- After adding/replacing GIFs you must rebuild (swift build / swift run)
  since SwiftPM copies resources into the build output at build time.

Delete this file once your real assets are in place (it is harmless to
leave it — it just gets copied alongside the GIFs).
